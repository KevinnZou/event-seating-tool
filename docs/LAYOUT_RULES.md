# 场地整理与过道

场地图顶部新增“一键整理”“添加过道”和“吸附网格（20）”。

1. 有实际通道时，先点“添加过道”，设置位置和宽高，黄底斜线区域表示禁放桌位。默认创建纵贯画布的中央通道，可改成横向或侧边通道。
2. 点“一键整理”，调整每行最多桌数、列间净距、行间净距。未标记过道时默认预留中央过道，可以关闭；已标记的过道始终保留并避让。
3. 查看实时预览后点“确认整理布局”。只改未锁定桌位置，宾客安排和人数不变；支持撤销/重做。位置与过道会保存到本机，参数只用于当次操作。
4. 新增桌会找现有网格空位，不挪其他桌。放不下时拒绝新增，可扩大画布或重新整理后再加。

舞台、入口、自定义区域和过道都参与自动避让；桌面到区域边界另留24画布单位。桌径96，以上单位均为示意坐标。未标记的真实过道不会被自动识别；不会自动移动舞台、入口或删除任何区域。

过道与锁定桌冲突时须先解锁并移桌。添加/移动过道可能覆盖既有桌位，会显示布局警告；整理修正前不会偷偷挪桌。手动拖桌/输入桌坐标则直接禁止进入过道或缓冲区。桌间其他重叠仍由原警告机制提示。

行列排布是确定性网格启发式；障碍会占用候选格，实际每行可能少于上限。空间不足或规则不适合时整次回滚，可减少每行桌数、调整间距或扩大画布。

数据兼容：Dexie4不改原记录。完整JSON保留过道，原V1/V2备份仍可读取；带过道的备份须用本次或后续版本恢复。旧V0.2不认识aisle区域，会拒绝恢复。更新前先备份并关闭其他旧版本标签页。
