## 性能记录

虚构300/500人分别含一组4人家庭，全部安排到30/50桌；不是用最大桌号推算桌数。名单采用50组分页，筛选/全选/统计仍基于全部数据；校验用精确ID定位，不受分页影响。

| 数据规模   | 项目     | 导入工作流耗时 | 搜索至目标可见 |
| ---------- | -------- | -------------- | -------------- |
| 300人/30桌 | 桌面     | 387ms          | 34ms           |
| 300人/30桌 | 手机仿真 | 387ms          | 33ms           |
| 500人/50桌 | 桌面     | 371ms          | 54ms           |
| 500人/50桌 | 手机仿真 | 326ms          | 47ms           |

这包括自动化交互、DOM更新和断言等待，并非纯算法耗时或跨设备性能承诺。此前500人搜索约1–2秒；移除重复拼音计算和超量DOM后得到上述结果。纯规划/统计另有300与500人3秒预算单测。
