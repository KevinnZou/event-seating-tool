## 性能记录

虚构300/500人分别含一组4人家庭，全部安排到30/50桌；不是用最大桌号推算桌数。名单采用50组分页，筛选/全选/统计仍基于全部数据；校验用精确ID定位，不受分页影响。

| 数据规模   | 项目     | 导入工作流耗时 | 搜索至目标可见 |
| ---------- | -------- | -------------- | -------------- |
| 300人/30桌 | 桌面     | 387ms          | 34ms           |
| 300人/30桌 | 手机仿真 | 387ms          | 33ms           |
| 500人/50桌 | 桌面     | 371ms          | 54ms           |
| 500人/50桌 | 手机仿真 | 326ms          | 47ms           |

这包括自动化交互、DOM更新和断言等待，并非纯算法耗时或跨设备性能承诺。此前500人搜索约1–2秒；移除重复拼音计算和超量DOM后得到上述结果。纯规划/统计另有300与500人3秒预算单测。

## 视觉和打印复查

沿用初始Image Gen概念（design/concept.png）及设计提示（design/PROMPT.md）的冷灰/白色/深青、中文系统字体与等宽数字，按新增M2–M4功能扩展，不虚称新工作台与初始首页示意逐像素相同。

先在内置浏览器核对真实本地首页与工作台，再通过Playwright记录桌面/手机截图；使用view_image同轮对照概念与最新board/import/export截图。桌面视口与概念原生1504×1046一致；手机全页长图缩放用于总览，功能测试使用原生390×664视口。

| 复查点     | 结果/有意差异                                                                       |
| ---------- | ----------------------------------------------------------------------------------- |
| 布局       | 首页活动行保留；工作台增加未安排区+桌卡，手机单列；不把原始概念的辅助小图当首页图片 |
| 色彩       | 白色表面、冷灰背景、深青操作与细边框，无远程照片/字体/渐变                          |
| 字体       | 中文系统字体、32px主标题、14px控件、tabular数字；长名称允许换行                     |
| 控件       | 按钮/选择菜单/表单统一；修复预览checkbox最小宽度误用及确认栏可见性                  |
| 首屏文案   | 保留品牌、首页标题与本机提示；新增导入、导出、撤销、备份等均来自授权路线            |
