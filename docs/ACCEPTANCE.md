## 设计复查

概念：`design/concept.png`，由内置 Image Gen 生成。提示词核心：中文智能排桌助手、白色顶部导航、冷灰背景#f5f7f8、深青#14665f、1180px内容宽、首页活动行/创建按钮/隐私说明、工作区统计横栏与桌位/宾客原生表单；虚构人物，禁用照片/渐变/额外模块。生成完整提示方向与token记录在DECISIONS；设计参考不进入运行时资源。

先使用内置浏览器实测首页→虚构演示→整组移桌，并查看原生截图；Playwright自动化截图保存为 `design/home-chromium.png`、`design/workspace-chromium.png` 及两个mobile版本。桌面视口1504×1046与概念原始尺寸一致，手机390×664、deviceScaleFactor 3；fullPage图片高度随内容增长。最终使用view_image同轮查看概念和最新实现，不用仅通过构建替代视觉检查。

| 比较点         | 结论与修正                                                                           |
| -------------- | ------------------------------------------------------------------------------------ |
| 配色           | 白色表面、冷灰背景、深青主按钮一致，无渐变/照片/外部资产                             |
| 布局           | 首页1180px活动行；工作区双列；手机转单列，宾客逐组行避免裁切操作                     |
| 字体           | 中文系统无衬线、32px标题、14px控件、数字tabular；表头保持可读                        |
| 组件/留白      | 10px面板圆角、细边框、安静的操作行；没有概念小图的浮动叠层                           |
| 文案           | 核心导航、首页标题、新建/进入/试用入口保留；新增编辑/复制/删除和M4未提供说明源于规格 |
| 人数与真实状态 | 概念示意数值改成数据库实时数据；首页18是测试新增7人后的结果，工作区截图为新增前11人  |
| 手机交互       | 整组选择菜单可操作，编辑/删除可见；修正早期狭窄表格列标题和右侧操作挤压              |
