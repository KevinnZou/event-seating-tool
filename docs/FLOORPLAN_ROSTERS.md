# 场地图名单总览

活动工作区 → 场地平面图 → 勾选工具栏“显示宾客名单”。关闭后回到原简洁圆桌视图。

- 各桌直接显示宾客组名称和×人数，待定宾客另有标记。同名记录分别显示；未安排宾客仍在原侧栏。
- 名单较多时在桌卡内部滚动，名称换行；没有按条数截断。可点桌卡头部查看原桌位详情并使用菜单换桌，名单即时同步。
- 名单显示时扩大画布显示间距，保持桌位、舞台和过道的真实坐标；画布支持滚动、缩放。切换时定位选中桌或第一桌；调整布局时拖桌卡头部，名单内部滚动不会移动桌位。
- 显示状态存放在活动URL的roster=1参数，刷新及视图切换后保留。没有新增本地数据库字段，不影响JSON兼容性和活动隔离。
- SVG/PNG场地图继续只包含桌号与人数。姓名名单仍通过原宾客报表交付，本轮没有将姓名加入原场地图导出。

实现：RoundTable.tsx独立承担桌卡展示，PlanCanvas负责交互；planPresentation纯函数统一将屏幕拖动反算为真实坐标，之后仍由原service校验过道、锁定和边界。

验证覆盖：家庭4人、同名2组、待定、空桌、换桌同步、刷新与开关、视图切换不改坐标；单桌26组与长姓名完整渲染；显示缩放下真实鼠标拖动、数字坐标、键盘移动与名单聚焦。新增纯函数测试覆盖不同缩放、反向位移、零位移和无效比例。

截图使用虚构数据：output/playwright/rosters/names-*.png。设置CAPTURE_ROSTERS=1执行浏览器测试可重拍。

测试同步说明：新增键盘流程在提交数字坐标后，先等待桌卡恢复可操作再发送方向键。输入框手填值不能证明事务已经结束；locator.press也不会替调用方等待disabled结束。本轮没有增加重试、放宽坐标/人数断言或跳过移动端配置。
