## 交付内容

包含多活动本地保存、桌位与宾客组管理、安全导入/JSON恢复、整组移动与撤销、人数校验、规则排桌建议、场地图/过道/自动整理、命名方案、名单报表与场地图导出、离线重开和应用文件恢复入口。新增场地图每桌宾客名单开关，按组显示人数并保留同名独立记录。

浏览器存储仍为IndexedDB，未增加账号、后端、云数据库、LLM或名单上传。内置示例与测试全部虚构；未读取旧归档名单或修改旧项目。

## 使用与迁移

首次打开线上地址时没有个人活动。请在本地原地址下载完整JSON，再在新地址导入为新活动并核对人数。不同域名、端口和浏览器不共享本机活动。后续清理浏览器数据前仍需下载备份。

名单开关作用于交互场地图；SVG/PNG保留原桌号与人数样式，完整姓名使用宾客报表。场地坐标用于示意，规则建议须预览确认。
